# Проект 4: Система онлайн-записи (бронирования)

## Цель
Портфолио-проект для Kwork. Подходит салонам, клиникам, репетиторам, студиям. Хорошо показывает работу с датами, расписанием и уведомлениями.

## Стек
- Laravel (последняя стабильная версия), PHP 8.2+
- Livewire + Tailwind или Filament для админки
- Carbon для работы со временем, учёт часовых поясов
- Очереди и планировщик задач (Scheduler) для напоминаний
- MySQL или PostgreSQL

## Основные сущности
- Услуги (длительность, цена)
- Сотрудники / мастера и их расписание (рабочие дни, перерывы, выходные)
- Клиенты
- Записи (слот времени, статус: новая, подтверждена, отменена, выполнена)

## MVP (версия 1)
1. Каталог услуг и выбор мастера
2. Расчёт свободных слотов с учётом расписания и уже занятых записей
3. Публичная страница записи без регистрации (имя, телефон)
4. Админ-панель: календарь записей, управление услугами и мастерами
5. Подтверждение и отмена записи
6. Напоминания клиенту за сутки и за 2 часа (email или Telegram)

## Развитие (по этапам)
- Этап 2: личный кабинет клиента, история записей
- Этап 3: онлайн-оплата или предоплата
- Этап 4: несколько филиалов
- Этап 5: SaaS-режим, где несколько компаний работают в одной системе (мультитенантность)

## Требования для портфолио
- Демо с тестовыми данными и доступом в админку
- README со скриншотами публичной страницы записи и календаря
- Тесты на расчёт слотов (главная логика проекта): пересечения, перерывы, границы дня

## Инструкции для Claude Code
- Расчёт слотов вынести в отдельный сервис с юнит-тестами
- Все даты хранить в UTC, показывать в часовом поясе бизнеса
- Перед стартом предложить структуру БД и алгоритм поиска свободных слотов
- Интерфейс на русском языке
